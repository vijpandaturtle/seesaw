Seesaw

A multi-agent system that automates the end-to-end hypothesis → experiment → critique loop in mechanistic interpretability research.

GitHub Live Dashboard ↗ Build Log ↗

Overview

You ask a research question. Scout picks one of eight hand-coded pathways and chooses its inputs, and you approve both before anything runs on a model. Lens runs the pathway, and Quill reviews the result like a peer reviewer. Every result is labelled with how strong its evidence is (correlational, estimate or causal) and whether its controls ran.

Scout question → research plan → Lens plan → results bundle → Quill bundle → critique report

Get started

Install with the experiment stack, add an Anthropic key, and ask a question whose answer is already known, so you can check the verdict.

# install (Lens needs torch + TransformerLens)
uv venv .venv --python 3.12 && source .venv/bin/activate
uv pip install -e ".[experiments]"
cp .env.example .env   # set ANTHROPIC_API_KEY

# run a job, approving at each gate as it goes
seesaw jobs submit "Does the model use the gender a job title implies to choose 'she' or 'he'?" \
  --pathway concept_direction --follow

Leave out --pathway and Scout picks one, or none, and plans the experiments itself. --search lets it search arXiv and the web. seesaw jobs rerun <id> --model <other> runs the same experiment on another model. Sample questions for every pathway are in the use-cases guide.

Pathways

Fixed investigations with a deterministic verdict, each checked against a known answer. They're the expert baseline Lens is judged against. Pathways run on any TransformerLens model, and rerunning a job with --model repeats the same experiment on another one, so models can be compared on identical inputs.

PathwayAnswers
circuit_discoveryWhat mechanism does the model use? Nominate heads, verify heads and MLPs by patching, and check the circuit is faithful.
concept_directionIs a concept a direction the model uses, and can it be removed or steered safely, beyond random directions?
probe_monitorWould a probe on the activations make a better detector than the words alone?
spurious_auditDoes the answer depend on an attribute it shouldn't, and can LEACE erase it without breaking the task?
factual_recallWhere does the model retrieve a fact? Causal tracing over layers and positions.
editing_comparisonIs the layer where a fact is traced the best layer to edit it with ROME?
model_diffingWhat did a fine-tune change, and in which weights?
feature_explainWhich SAE features drive this output, and what are they? (Needs a model with public SAEs; GPT-2 small for now.)

The Three Agents

The agents currently run on Claude.

🔭

Scout

The Research Planner

A ReAct agent that picks the pathway that answers your question and chooses its inputs, which are checked before you see them. When no pathway fits, it plans the experiments itself. It searches the literature only when you ask it to.

LangGraph ReAct · Firecrawl
🔬

Lens

The Experiment Runner

A LangGraph state machine that runs the pathway first, then any extra experiments in the plan, interprets each result, and can queue follow-ups. It runs text models through TransformerLens and vision-language models through lever.

LangGraph StateGraph · TransformerLens · SAELens
🪶

Quill

The Reviewer

Critiques the results like a peer reviewer, with the pathway's verdict as the primary evidence. It flags methodological gaps and unsupported conclusions, and writes follow-up specs Lens can run.

LangGraph StateGraph

Lens's Tools

18 tools for text models, labelled by the kind of evidence they give. Lens chains them nominate-then-verify: an estimate picks candidates, and a causal intervention tests them.

KindTools
Descriptive
logit_lens · attention_pattern · direct_logit_attribution · linear_probe · feature_search · counterfactual
What the model represents or attends to. No causal claim.
Estimate
attribution_patching · feature_attribution · edge_attribution_patching · circuit_tracing
Gradient-based approximations that rank candidates cheaply. Never reported as effects.
Causal
ablation · activation_patching · head_patching · circuit_evaluation · path_patching · steering_vector · directional_ablation · feature_clamping
Interventions: change the model and measure what follows.

Six more tools cover vision-language models (LLaVA, Qwen-VL, CLIP), including vision ablation, image-token ablation and CLIP head ablation.

Deployment

Nothing always-on. Scout, Quill, and Lens's graph run on a Modal CPU app; Lens's experiment tools run on a Modal GPU app with per-second billing. A thin Next.js dashboard on Vercel queues jobs and reads state from a Postgres (Neon) job store — the dashboard never executes an agent directly.
